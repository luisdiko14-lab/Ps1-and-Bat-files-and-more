# Omega App Builder

This folder now includes a more complete app builder experience.

## Included files
- Ultimate_App_Builder.ps1: the main GUI app builder
- app_config.json: starter configuration file created when you click Create Template
- main_app.ps1: starter app script
- launch_app.bat: quick batch launcher
- README.txt: quick-start notes

## Features
- Create new files in the desktop PROJECT folder
- Save and edit files in a built-in editor
- Upload files into the project folder
- Run PowerShell, Python, and batch files
- Check for basic errors in PowerShell, Python, batch, and JSON files
- Create starter project files for faster app building
