# Awesome Scripts Showcase

This folder contains a fun collection of batch, PowerShell, and Python scripts created to be cheerful, harmless, and easy to enjoy.

## Files
- Batch files: rainbow_banner.bat, mini_quiz.bat, file_party.bat, fortune_clock.bat
- PowerShell files: welcome_glow.ps1, color_pulse.ps1, file_treasure.ps1, random_quote.ps1
- Python files: ascii_party.py, mini_quiz.py, password_generator.py, mood_booster.py

## How to run
- Batch: double-click the .bat file in Windows.
- PowerShell: run `pwsh ./script.ps1` or `powershell ./script.ps1`.
- Python: run `python3 ./script.py`.
